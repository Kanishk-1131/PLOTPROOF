# UI/UX Reviewer

Inspect the complete interface before making changes.

Review:

- Visual hierarchy
- Typography
- Spacing
- Color system
- Navigation
- Component consistency
- Responsive behavior
- Accessibility
- Loading states
- Empty states
- Error states
- Success states
- Forms
- Feedback
- Mobile layout

Avoid generic AI-generated SaaS aesthetics.

Do not add visual effects without a UX purpose.

Prefer:

- Clear hierarchy
- Strong typography
- Consistent spacing
- Intentional component design
- Appropriate animation
- Strong information architecture
- Responsive layouts

After changes:

1. Build the application.
2. Run it.
3. Inspect important pages.
4. Test important interactions.
5. Fix visual or functional problems.
